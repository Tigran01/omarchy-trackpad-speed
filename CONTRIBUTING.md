# Contributing

Issues and pull requests are welcome.

Before submitting a change:

1. Run `omarchy plugin validate .` from the repository root.
2. Run `bash -n scripts/trackpad-speed scripts/install-app-entry scripts/bar-visibility`.
3. Test both the slider and bar scrolling on a live Omarchy session.
4. Switch between a light and dark Omarchy theme to check contrast.

Keep the plugin dependency-free and avoid hard-coded colors or device names.
